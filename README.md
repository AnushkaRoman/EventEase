# EventEase – Smart College Event Registration & Management

EventEase is an interactive web application designed to simplify college event registration and participant management.

The application allows students to register for college events, while JavaScript manages validation, registration data, searching, filtering, and deletion dynamically.

## 🎯 Objective

The main objective of EventEase is to design and develop a web application using:

- HTML
- CSS
- JavaScript
- Arrays
- JSON

The project demonstrates input validation, error messages, event handling, DOM manipulation, searching, filtering, and dynamic data management.

## ✨ Features

- 📝 Student event registration
- ✅ Form input validation
- ⚠️ Proper validation and error messages
- 📦 Registration data stored using JavaScript arrays
- 📄 JSON objects for registration records
- 🔍 Search registrations by name or email
- 🔽 Filter registrations by event
- 🗑️ Delete registrations
- 🔢 Dynamic registration count
- 💾 Local storage support
- 🔄 Dynamic table updates
- 📱 Responsive interface

## 🛠️ Technologies Used

| Technology | Purpose |
